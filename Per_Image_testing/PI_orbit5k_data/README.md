# Data Description

## Contents

This directory contains **[Persistence images for the ORBIT5K simulation]**.

The generated files include:

* `[PI_orbit_r*_arrays.Rdata]`: [Persistence images of the first group for each parameter r.]
* `[PI_orbit_second_r*_arrays.Rdata]`: [Persistence images of the second group for each parameter r.]

## How to Generate

The data are generated by:

```text
[../orbit5k_data_PI.R]
```
## Output

After running the script, the generated data will be saved in this directory.

> Note: The generated data files are not tracked by Git.
