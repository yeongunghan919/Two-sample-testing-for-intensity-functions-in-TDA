# Data Description

## Contents

This directory contains **[Persistence images for the Torus simulation]**.

The generated files include:

* `[data_pi_torus_root.Rdata]`: [Persistence images of the torus data using the root weight.]

## How to Generate

The data are generated by:

```text
[../Torus_data_PI.R]
```
## Output

After running the script, the generated data will be saved in this directory.

> Note: The generated data files are not tracked by Git.
