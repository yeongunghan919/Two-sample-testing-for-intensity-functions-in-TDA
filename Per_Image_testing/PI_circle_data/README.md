# Data Description

## Contents

This directory contains **[Persistence images for the Circles simulation]**.

The generated files include:

* `[data_pi_onecircle_*.Rdata]`: [Persistence images of the one-circle data group for each weight function:constant, artan, linear.]
* `[data_pi_twocircle_*.Rdata`: [Persistence images of the two-circle data group for each weight function.]

## How to Generate

The data are generated by:

```text
[../circle_data_PI.R]
```
## Output

After running the script, the generated data will be saved in this directory.

> Note: The generated data files are not tracked by Git.
