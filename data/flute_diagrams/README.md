# Data Description

## Contents

This directory contains **[Persistence diagrams for Musical instruments data analysis.]**.

The generated files include:

* `[flute_onedim_*.csv]`: [Persistence diagrams from the flute data.]

## How to Generate

The data are generated by:

```text
[Sound_data.R] <- [../data_generation_toJSON_Circles.R] with [../Flute A full time series.csv]
```

## Output

After running the script, the generated files will be saved in this directory.

> Note: The generated data files are not tracked by Git. 
The musical instrument recordings [Flute A full time series.csv] were obtained from the public repository
https://github.com/MattO-Reilly/TDATimeSeriesAnalysis, which was publicly available at the time of data acquisition 
but is no longer accessible.
