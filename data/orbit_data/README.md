# Data Description

## Contents

This directory contains **[ORBIT5K data set.]**.

The generated files include:

* `[orbit5k_X_original_*.npy]`: [The orbit data.]
* `[orbit5k_y.npy]`: [The label data for the orbit data.]
* `[PD_r*.pkl]`: [Persistence diagrams of the obit data with r=0, 2, 4.]
* `[small_PD.pkl]`: [A subset of persistence diagrams of the orbit data]


## How to Generate

Run the following script from the project root:

```bash
[command to run the code]
```

The data are generated by:

```text
[npc=50_nset=100onepd.Rdata] <- [../orbit5k_generate_data.py]
[PD_r*.pkl] <- [../../simulations/orbit5k/orbit5k.ipynb]
[small_PD.pkl]` <- [../../simulations/orbit5k/orbit5k.ipynb]
```

## Output

After running the script, the generated files will be saved in this directory.

> Note: The generated data files are not tracked by Git.
