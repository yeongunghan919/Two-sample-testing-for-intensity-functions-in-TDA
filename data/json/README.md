# Data Description

## Contents

This directory contains **[Persistence diagrams for Circles and Torus simulations]**.

The generated files include:

* `[npc=50_nset=100onepd.json]`: [Persistence diagrams from one circle.]
* `[npc=50_nset=100twopd.json]`: [Persistence diagrams from two circles.]
* `[npc=50_nset=100torus_pd.json]`: [Persistence diagrams from torus.]



## How to Generate

Run the following script from the project root:

```bash
[command to run the code]
```

The data are generated by:

```text
[npc=50_nset=100onepd.json] <- [../data_generation_toJSON_Circles.R]
[npc=50_nset=100twopd.json] <- [../data_generation_toJSON_Circles.R]
[npc=50_nset=100torus_pd.json] <- [../data_generation_toJSON_Torus.R]
```

## Output

After running the script, the generated files will be saved in this directory.

> Note: The generated data files are not tracked by Git.
